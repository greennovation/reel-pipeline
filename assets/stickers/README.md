# Стикеры-маскоты

Положи сюда свои PNG-стикеры с прозрачным фоном (маскоты для хук-обложек).
Имя задаётся в `обложка.стикер` Markdown-описания ролика, например `star` для
файла `star.png`. Пустое имя или отсутствующий файл оставляют обложку без стикера.

Снять фон: `pip install rembg onnxruntime` → `rembg i in.png out.png` (модель u2net ~170МБ).
